### 🚀 Sobre mim

Construo sistemas web de ponta a ponta: da modelagem do banco à interface, com foco em regras de negócio corretas, segurança e software que a equipe usa todo dia.
Hoje trabalho com uma plataforma para empresas que participam de **licitações públicas**: captação automática de editais, análise de editais com IA, esteira Kanban/CRM e gestão de acervo documental.

### 🛠️ Habilidades

**Backend**
- Node.js + Express + TypeScript (APIs REST, autenticação JWT, permissões por perfil)
- Integrações HTTP com portais públicos e scraping (PNCP e outros)
- Jobs agendados, uploads e processamento de PDF

**Frontend**
- React 19 + Vite + Tailwind CSS
- Layout responsivo mobile-first e acessibilidade

**Banco de dados**
- PostgreSQL: modelagem relacional, transações, índices, JSONB, busca textual em português
- Migrações e saída de modelo chave-valor para tabelas relacionais
- Supabase (Postgres gerenciado e Storage privado)

**Inteligência artificial**
- Integração com LLMs (Claude e Gemini): extração estruturada de dados de documentos, prompts e tratamento de cotas/retry

**Infraestrutura**
- Deploy em VM Linux (systemd + Caddy com HTTPS), Git e GitHub

**Domínio**
- Licitações públicas (Lei 14.133/2021), habilitação, PNCP e LGPD aplicada a documentos de empresas
